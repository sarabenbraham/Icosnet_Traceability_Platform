# ICOSNET DSI Platform

An internal platform developed as part of an internship project to support the digitalization and management of internal processes within an Information Systems Department.

## Overview

This project aims to provide a centralized platform for managing internal workflows and improving process traceability. The platform is designed to be modular, allowing new features and services to be integrated as the project evolves.

## Objectives

- Digitalize internal DSI processes
- Improve workflow traceability
- Facilitate process monitoring
- Support future extensions and integrations
- Provide a scalable and maintainable architecture

## Technologies

- Python
- Django
- PostgreSQL
- Docker (planned)
- Git & GitHub
